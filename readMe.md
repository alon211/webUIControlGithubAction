该项目要求创建一个webUI，基于python flask框架，实现功能1：github拉去特定仓库文件修改后推送到github。功能2：可以启动该仓库的指定action的工作流，并获取日志和执行结果。工作流里获取到下载链接，可以存放在配置的指定目录下。要求配置里设置token，github仓库，下载目录，用sqlite来存储配置。功能3.要求本地测试好可以快速生成docker来部署。所有功能验证测试都要用chrome-dev 工具测试验证并截图。环境配置都要在项目级，默认使用目录下的虚拟环境。在开发时，先从用chrome-dev搜索需要的功能是否已经在github上有成熟方案，如果有直接用成熟的。如果没有，再自己写。
