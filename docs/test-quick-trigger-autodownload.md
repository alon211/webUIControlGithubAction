# 快速触发自动下载 - 测试指南

## 🎯 测试目的

验证快速触发功能是否在工作流完成后自动下载产物。

## 📋 前置条件

- ✅ Flask 应用正在运行（http://localhost:5000）
- ✅ 已配置 GitHub Token
- ✅ 已配置快速触发（邮件提取工作流）
- ✅ 已设置下载目录

## 🚀 测试步骤

### 步骤 1: 打开应用

在浏览器中访问：
```
http://localhost:5000
```

### 步骤 2: 检查快速触发面板

应该看到：
```
⚡ 快速触发
┌─────────────────────────────────┐
│ 邮件提取工作流                  │
│ ✓ 上次成功                      │
│ [运行]                          │
└─────────────────────────────────┘
```

### 步骤 3: 点击运行按钮

1. 点击绿色"运行"按钮
2. 在确认对话框中点击"确定"

### 步骤 4: 观察状态变化

**预期变化**：
```
点击后立即:
┌─────────────────────────────────┐
│ 邮件提取工作流                  │
│ ⟳ 进行中                       │
│ [⟳ 运行中]  (灰色，禁用)        │
└─────────────────────────────────┘

2-5分钟后（工作流完成）:
┌─────────────────────────────────┐
│ 邮件提取工作流                  │
│ ✓ 上次成功                      │
│ [运行]  (绿色，可用)            │
└─────────────────────────────────┘
```

### 步骤 5: 检查浏览器控制台

1. **打开开发者工具**：按 `F12`
2. **切换到 Console 标签**
3. **观察输出**（应该在工作流完成后看到）：

```
下载产物 (1/1): extraction-results-23007503230
产物 "extraction-results-23007503230" 下载成功: data\extraction-results-23007503230
```

### 步骤 6: 验证下载文件

**方法 1: 在文件资源管理器中打开**
```
c:\dockerVolumn\webUIControlGithubAction\data\
```

应该看到新的产物文件夹：
```
extraction-results-23007503230\
└── 2026-03-12_143723\
    └── summary.json
```

**方法 2: 使用命令行检查**
```bash
cd c:\dockerVolumn\webUIControlGithubAction\data
dir extraction-results-*
```

## ✅ 成功标准

测试成功的标志：
- [ ] 工作流状态从"进行中"变为"上次成功"
- [ ] 浏览器控制台显示下载日志
- [ ] 下载目录中出现新的产物文件夹
- [ ] 文件夹中包含提取的文件

## ❌ 如果失败

### 问题 1: 控制台没有任何输出

**原因**: JavaScript 可能未加载

**解决**:
1. 硬刷新页面（`Ctrl + F5`）
2. 清除浏览器缓存
3. 检查是否有 JavaScript 错误

### 问题 2: 控制台显示错误

**常见错误**：

| 错误信息 | 原因 | 解决方案 |
|---------|------|----------|
| `获取执行记录失败` | GitHub Token 无效 | 检查 Token 配置 |
| `获取产物失败` | 产物未生成 | 等待工作流完全完成（2-5分钟） |
| `下载失败: 磁盘空间不足` | 磁盘空间不够 | 清理磁盘空间 |
| `下载失败: 创建下载目录失败` | 目录权限问题 | 检查目录权限 |

### 问题 3: 工作流显示"上次成功"但没有文件

**原因**:
- 快速触发配置的是历史记录，不是刚刚触发的运行
- 需要等几秒让 GitHub API 更新

**解决**:
1. 检查控制台日志中的 `run_id`
2. 确认这个 ID 是刚刚触发的运行
3. 在工作流执行记录页面手动下载验证

## 🔍 调试模式

### 启用详细日志

在浏览器控制台中执行：
```javascript
// 查看状态监控是否运行
console.log('监控间隔:', statusCheckInterval);
console.log('之前的状态:', previousStatus);
```

### 手动触发下载

在控制台中执行：
```javascript
// 手动获取产物列表
$.ajax({
    url: '/workflows/api/artifacts',
    method: 'POST',
    contentType: 'application/json',
    data: JSON.stringify({
        repo: 'alon211/expense-reimbursement-email-automation',
        run_id: 23007503230  // 替换为最新的 run_id
    }),
    success: function(data) {
        console.log('产物列表:', data);
    }
});
```
