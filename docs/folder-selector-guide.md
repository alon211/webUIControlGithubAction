# 文件夹选择器使用说明

## 🔍 为什么按钮显示"上传"或"Upload"？

这是浏览器的默认行为。HTML 的 `<input type="file" webkitdirectory>` 元素被设计用于文件上传，所以我们复用它来选择文件夹。

**重要**：虽然按钮显示"上传"，但实际上我们是用来**选择保存位置**，而不是上传文件！

## ✅ 正确使用方法

### 配置页面：设置默认下载目录

1. 点击 **「选择文件夹」** 按钮
2. 在弹出的对话框中：
   - 浏览到您想保存产物的文件夹
   - **点击该文件夹内的任意一个文件**
   - 点击「选择」或「打开」
3. 系统会自动提取该文件的父目录路径

**示例**：
```
想保存到: C:\Users\YourName\Downloads\GitHubArtifacts
操作步骤:
1. 导航到 C:\Users\YourName\Downloads\GitHubArtifacts
2. 点击该文件夹内的任意文件（如 readme.txt）
3. 系统自动识别: C:\Users\YourName\Downloads\GitHubArtifacts
```

### 产物下载：选择保存位置

点击「下载」按钮后：

1. 系统会弹出目录选择对话框
2. 对话框可能显示：
   - "选择文件上传"
   - "Upload files"
   - 或类似字样
3. **请忽略这些字样**，按照以下步骤操作：
   - 导航到您想保存产物的文件夹
   - 选择该文件夹内的任意一个文件
   - 点击「选择」
4. 系统会自动：
   - 提取文件夹路径
   - 将产物下载到该文件夹
   - 自动解压

## 📝 常见问题

### Q: 为什么不直接选择文件夹？
**A**: 浏览器的安全限制，HTML 文件输入只能选择文件，不能直接选择文件夹。我们通过选择文件来间接获取文件夹路径。

### Q: 会上传我的文件吗？
**A**: **不会！** 我们只读取文件夹路径，不会上传任何文件。数据流向是：
```
GitHub → 您的电脑（下载）
```

### Q: 浏览器兼容性
**A**: 需要现代浏览器支持：
- Chrome 15+
- Firefox 50+
- Safari 11.1+
- Edge 15+

### Q: 显示"No files selected"怎么办？
**A**:
1. 确保您选择的是一个文件，而不是文件夹
2. 如果只看到文件夹名称，尝试进入文件夹后选择里面的文件
3. 某些浏览器需要您选择文件后点击「打开」按钮

## 🎯 最佳实践

### Windows 用户

```
推荐路径格式:
✅ C:\Users\YourName\Downloads\Artifacts
✅ D:\GitHubActions\产物
✅ \\server\share\artifacts (网络路径)

避免:
❌ 路径包含特殊字符
❌ 路径过长（> 260字符）
❂ 没有写权限的目录
```

### Mac/Linux 用户

```
推荐路径格式:
✅ /Users/yourname/Downloads/artifacts
✅ /home/yourname/github-artifacts
✅ /mnt/data/artifacts

避免:
❌ 没有写权限的目录
❂ 系统目录（/etc, /usr, /sys 等）
```

## 🔧 手动输入路径

如果文件夹选择器不工作，您也可以：

1. 点击输入框
2. 手动输入完整路径
3. 点击「保存配置」

**示例**:
```
Windows: C:\Users\YourName\Downloads\Artifacts
Mac: /Users/yourname/Downloads/Artifacts
Linux: /home/yourname/Downloads/Artifacts
```

## 💡 提示

- 第一次使用时，建议先选择一个测试文件夹验证功能
- 确保选择的文件夹有足够的磁盘空间
- 确保您有该文件夹的写权限
- 如果使用网络路径，确保网络连接正常
